🚀 COMO USAR AGORA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  GERAR UM POST (Interface Web)

   1. Abra: http://localhost:3001/gerador-posts-ia.html
   2. Cole: https://www.mercadolivre.com.br/[seu-produto]/p/ML[ID]
   3. Clique: "Gerar"
   4. Veja o preview do post
   5. Clique: "Salvar Post"
   6. ✨ Post publicado em /blog/


2️⃣  GERENCIAR LINKS DE AFILIADO

   1. Abra: http://localhost:3001/gerenciador-afiliados.html
   2. Cole seus links de afiliado
   3. Clique: "Salvar"
   4. ✨ Próximos posts usarão seus links


3️⃣  USANDO A API (Para Integração)

   # Gerar post
   curl -X POST http://localhost:3001/api/gerar-post-ia \
     -H "Content-Type: application/json" \
     -d '{"url": "https://..."}'

   # Salvar post
   curl -X POST http://localhost:3001/api/salvar-post \
     -H "Content-Type: application/json" \
     -d '{...post data...}'

   # Ver estatísticas
   curl http://localhost:3001/api/afiliados/stats

      ↓

      ↓
