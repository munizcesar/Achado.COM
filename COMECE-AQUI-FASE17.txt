SITUAÇÃO 1: Quero gerar um post novo
  1. Abra: http://localhost:3001/gerador-posts-ia.html
  2. Cole link do ML
  3. Clique "Gerar"
  4. Clique "Salvar Post"
  ✨ Post criado em /blog/nome-do-produto.html

SITUAÇÃO 2: Quero adicionar meu link de afiliado
  1. Abra: http://localhost:3001/gerenciador-afiliados.html
  2. Cole seu link de afiliado
  3. Clique "Salvar"
  ✨ Próximos posts usarão seu link

SITUAÇÃO 3: Quero editar um post
  1. Abra arquivo em /blog/nome.html
  2. Edite com VS Code ou Notepad
  3. Salve
  ✨ Mudanças aplicadas

SITUAÇÃO 4: Quero ver quanto tá gerando
  1. Abra: http://localhost:3001/api/afiliados/stats
  2. Veja cliques por produto/página
  ✨ Analytics em tempo real

SITUAÇÃO 5: Quero usar IA real
  1. Leia: INTEGRACAO-IA-REAL.md
  2. Escolha: Groq (recomendado) / OpenAI / HF
  3. Configure API Key
  4. Integre 30 minutos
  ✨ IA real funcionando
