> **Onde o Premium Vira Achado**

Página de divulgação de ofertas e produtos verificados de marketplaces confiáveis (Mercado Livre, Magalu, Amazon).

## 🚀 Começar Agora

### Para Gerar Posts Automaticamente
1. Abra: **http://localhost:3001/gerador-posts-ia.html**
2. Cole um link do Mercado Livre
3. Clique **"Gerar"**
4. Clique **"Salvar Post"**
5. Pronto!

### Para Gerenciar Links de Afiliado
1. Abra: **http://localhost:3001/gerenciador-afiliados.html**
2. Cole seus links de afiliado
3. Clique **"Salvar"**
4. Automático! Próximos posts usarão seus links
