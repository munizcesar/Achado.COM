Mudancas Realizadas

1. Meta Tags Open Graph Completas

  • og:title - Titulo da página
  • og:description - Descrição resumida
  • og:image - URL da imagem (JPG)
  • og:image:secure_url - Versão HTTPS
  • og:image:width - 1200px
  • og:image:height - 630px
  • og:image:type - image/jpeg
  • og:image:alt - Descrição para acessibilidade
  • og:url - URL canônica
  • og:type - Tipo de conteúdo

2. Twitter Card Tags

  • twitter:card - summary_large_image
  • twitter:title - Titulo otimizado
  • twitter:description - Descrição para Twitter
  • twitter:image - URL da imagem

  • og-previa.jpg - 1200x630px (resposta otimizada)

Se a Imagem Ainda Nao Aparecer

  1. Limpar Cache do Facebook:
    Acesse o Facebook Debugger, copie a URL completa (https://achadocerto.vip/) e clique em "Compartilhar" para forçar atualização.
  2. Verificar Acessibilidade:
    Confirme que https://achadocerto.vip/ responde corretamente em HTTPS.
  3. Aguardar Propagação:
    Em alguns casos, leva 24-48 horas para as alterações serem refletidas globalmente.
  4. Verificar robots.txt:
    Confirme que não está bloqueando facebookexternalhit ou Googlebot.

Checklist de Validacao

  • Arquivo og-previa.jpg existe e é acessível
  • Dimensões corretas: 1200x630px
  • Formato: JPEG (suportado por todas as redes)
  • Meta tags Open Graph completas no index.html
  • Twitter Card tags presentes
  • og:image:secure_url configurado
  • og:image:alt adicionado (acessibilidade)
  • robots.txt não bloqueia crawlers sociais
  • share.js atualizado para passar imagem
  • Posts secundários também atualizados
