┌─ FLUXO DO SISTEMA ───────────────────────────────────────────────────────────┐
│                                                                              │
│  Usuario cola URL do ML                                                      │
│           ↓                                                                   │
│  [POST /api/gerar-post-ia]                                                  │
│           ↓                                                                   │
│  Tenta buscar dados da API (Mercado Livre)                                  │
│           ↓                                                                   │
│  ├─→ API OK? → Extrai dados reais                                          │
│  └─→ API DOWN? → Usa fallback inteligente                                  │
│           ↓                                                                   │
│  Gera conteúdo (IA simulada - pronto para IA real)                          │
│           ↓                                                                   │
│  Formata como HTML (usando POST-BOILERPLATE)                                │
│           ↓                                                                   │
│  Auto-insere link de afiliado (se existir)                                  │
│           ↓                                                                   │
│  Retorna HTML pronto para preview                                           │
│           ↓                                                                   │
│  Usuario clica "Salvar"                                                      │
│           ↓                                                                   │
│  [POST /api/salvar-post]                                                    │
│           ↓                                                                   │
│  Sanitiza nome do arquivo                                                   │
│           ↓                                                                   │
│  Salva em /blog/ com nome auto-gerado                                       │
│           ↓                                                                   │
│  ✨ POST PUBLICADO ✨                                                        │
│                                                                              │
