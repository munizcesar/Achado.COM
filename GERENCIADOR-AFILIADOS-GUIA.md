## 🚀 COMO USAR (Super Simples!)

### **PASSO 1: Abra o Gerenciador**
```
http://localhost:3001/gerenciador-afiliados.html
```

### **PASSO 2: Você verá uma tela assim:**
```
┌─────────────────────────────────────────┐
│  💼 Gerenciador de Afiliados           │
│                                         │
│  📊 Produtos: 9 | Cliques: 0           │
│                                         │
│  ┌──────────────────────────────────┐ │
│  │ Motorola Moto E14                │ │
│  │ 🏷️ tech | ID: motorola-moto-e14  │ │
│  │ 📊 0 cliques                      │ │
│  │                                  │ │
│  │ Link de Afiliado:                │ │
│  │ [____________________________]   │ │
│  │                                  │ │
│  │ [Salvar]  [Testar]              │ │
│  └──────────────────────────────────┘ │
│                                         │
│  (+ 8 outros produtos)                 │
└─────────────────────────────────────────┘
```

### **PASSO 3: Para cada produto:**

1. **Cole seu link de afiliado** na caixa de texto
   - Exemplo: `https://www.mercadolivre.com.br/motorola-moto-e14-64gb-preto-prismatico/p/MLB32154234?ref=seu_codigo_afiliado`

2. **Clique em "Salvar"**
   - Aparece ✅ "Link salvo com sucesso!"

3. **Pronto!** ✅ Seu link está ativo

### **PASSO 4: (Opcional) Testar o link**
- Clique em "Testar" para abrir o link em nova aba
- Verifique se abre corretamente

## 🔗 **FORMATO DO LINK:**

Use esse padrão:
```
https://www.mercadolivre.com.br/[nome-do-produto]/p/[CODIGO]?ref=[SEU_CODIGO_AFILIADO]
```

**Exemplos reais:**
- ✅ `https://www.mercadolivre.com.br/motorola-moto-e14-64gb-preto-prismatico/p/MLB32154234?ref=seu_codigo`
- ✅ `https://www.mercadolivre.com.br/samsung-galaxy-a15-5g-128gb/p/MLB39012345?ref=seu_codigo&utm_source=achadocerto`

## ⚙️ **DÚVIDAS FREQUENTES:**

**P: Preciso reiniciar o servidor?**  
R: Não! O painel salva automaticamente via API.

**P: Posso editar depois?**  
R: Sim! Volte ao painel e clique em "Salvar" de novo.

**P: E se eu errar o link?**  
R: Clique "Testar" para verificar, ou cole um novo.

**P: Os cliques são rastreados?**  
R: SIM! Veja em "Cliques Totais" quantas conversões cada produto gera.
