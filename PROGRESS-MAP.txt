HOW TO USE IT
═════════════════════════════════════════════════════════════════════════════════

1️⃣  OPEN THE WEB INTERFACE
    http://localhost:3001/gerador-posts-ia.html

2️⃣  PASTE A MERCADO LIVRE URL
    https://www.mercadolivre.com.br/seu-produto/p/ML123

    System will create a preview in 2 seconds

4️⃣  REVIEW THE PREVIEW
    See the full HTML post with all meta tags

5️⃣  CLICK "SALVAR POST" (SAVE POST)
    File is created in /blog/ directory
