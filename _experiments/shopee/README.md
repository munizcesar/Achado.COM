# Experimentos Shopee

Scripts de testes com a API/scraping da Shopee.
Nenhum deles foi para produção.

## Arquivos
- `tmp-shopee-api.py` — teste de autenticação via API oficial
- `tmp-shopee-api2.py` — variação do teste
- `tmp-shopee-api3.py` — variação do teste
- `tmp-shopee-body.py` — teste de extração de body do produto
- `tmp-shopee-product.py` — teste de dados de produto
- `tmp-shopee-scrape.js` — tentativa de scraping via JS
- `tmp-shopee-shorturl.py` — encurtamento de links afiliados
- `tmp-shopee-shorturl2.py` — variação do encurtamento
