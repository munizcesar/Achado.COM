❓ DÚVIDAS COMUNS

P: O servidor não está iniciando?
R: Execute: cd backend && npm start
   Verifique se porta 3001 está disponível
   Abra: http://localhost:3001/api/health

P: Erro "API indisponível"?
R: É normal! Sistema usa fallback automaticamente
   Dados simulados mantêm tudo funcionando
   API do Mercado Livre às vezes retorna 403

P: Como editar um post depois de salvo?
R: Abra arquivo em /blog/nome-do-post.html
   Use editor de texto (VS Code, Notepad++, etc)
   Salve e pronto!

P: Como adicionar meu link de afiliado?
R: 1. Abra: http://localhost:3001/gerenciador-afiliados.html
   2. Cole seu link de afiliado
   3. Clique "Salvar"
   4. Pronto! Próximos posts usarão seu link

P: Qual IA está sendo usada?
R: Atualmente é simulada (dados fake realistas)
   Para IA real, siga: INTEGRACAO-IA-REAL.md
   Recomendação: Use Groq (gratuito e rápido)

⚡ DICAS DE USO

1. GERAR MÚLTIPLOS POSTS
   • Abra http://localhost:3001/gerador-posts-ia.html
   • Cole URL
   • Gere e salve
   • Repita com outro URL
   • Sistema cria novo arquivo para cada um

2. CUSTOMIZAR CONTEÚDO
   • IA gera base de 70%
   • Você adiciona toque pessoal (30%)
   • Edite arquivo HTML após salvar
   • Publish quando estiver pronto

3. RASTREAR PERFORMANCE
   • Acesse: http://localhost:3001/api/afiliados/stats
   • Veja quantos cliques cada link teve
   • Qual post gera mais conversão
   • Qual categoria vende mais

4. ADICIONAR CATEGORIA NOVA
   • Edite gerador-posts-ia.html
   • Atualize categorias em "Categoria:"
   • Customize prompt para aquela categoria
   • Teste!

🔧 TROUBLESHOOTING

PROBLEMA: Arquivo não salva
SOLUÇÃO:  • Verifique permissões em /blog/
          • Crie diretório se não existir
          • Reinicie servidor (npm start)

PROBLEMA: Link de afiliado não aparece
SOLUÇÃO:  • Abra gerenciador-afiliados.html
          • Cole link e clique Salvar
          • Gere novo post
          • Verificar affiliates.json tem link

PROBLEMA: Preview não carrega
SOLUÇÃO:  • Limpe cache do navegador (Ctrl+Shift+Del)
          • Recarregue página (F5)
          • Teste em navegador diferente

PROBLEMA: Conteúdo gerado está ruim
SOLUÇÃO:  • Edite manualmente após salvar
          • Customize prompts em server.js
          • Quando usar IA real, prompt melhor = resultado melhor

PROBLEMA: Server returns 500 error
SOLUÇÃO:  • Olhe logs no terminal (npm start)
          • Verifique se affiliates.json existe
          • Reinicie: npm start
